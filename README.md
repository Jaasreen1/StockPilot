# StockPilot

**Full-stack inventory management system built with Python, FastAPI, SQLite, and vanilla JavaScript.**

StockPilot is a local-first inventory dashboard with a REST API, product catalog, transactional stock movement tracking, and automatic low-stock indicators. It demonstrates full-stack application development, data validation, SQL transactions, automated integration testing, and CI.

## Features

- Create, search, edit, and delete products with unique SKUs
- Track categories, prices, current stock, and reorder thresholds
- Record **IN**, **OUT**, and **ADJUST** movements with immutable history
- Prevent negative stock using SQLite transactions
- Dashboard metrics: total products, units, inventory value, low-stock count
- **Inventory intelligence**: category valuation, reorder priorities, daily stock-movement aggregates
- **Downloadable CSV exports** for products and complete movement history (UTF-8 with BOM for spreadsheet compatibility)
- Spreadsheet-formula escaping for user-controlled CSV text fields
- Responsive dark-mode frontend using HTML, CSS, and JavaScript
- OpenAPI documentation automatically generated by FastAPI
- Integration tests using isolated SQLite databases and GitHub Actions CI

## Quick start

Requires Python **3.11+**.

```bash
git clone https://github.com/Jaasreen1/StockPilot.git
cd StockPilot
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
# source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Open **http://127.0.0.1:8000** for the dashboard, or **http://127.0.0.1:8000/docs** for interactive REST API documentation.

The application automatically creates `stockpilot.db` in the working directory. To choose another location, set the `STOCKPILOT_DB` environment variable **before** starting the application.

## Run tests

```bash
python -m unittest discover -s tests -v
```

GitHub Actions runs the integration suite on Python 3.11, 3.12, and 3.13.

## API routes

| Method | Route | Purpose |
|---|---|---|
| GET | `/api/health` | Health check |
| GET | `/api/products` | List, search, or filter low-stock products |
| POST | `/api/products` | Create product |
| PUT | `/api/products/{id}` | Update product metadata |
| DELETE | `/api/products/{id}` | Delete product without movement history |
| POST | `/api/products/{id}/movements` | Receive, ship, or adjust stock |
| GET | `/api/movements` | View recent movements |
| GET | `/api/metrics` | Inventory dashboard totals |
| GET | `/api/reports/overview` | Category summaries, reorder priorities and movement trends |
| GET | `/api/reports/products.csv` | Download all products as CSV |
| GET | `/api/reports/movements.csv` | Download full movement history as CSV |

Example request:

```json
{
  "sku": "KB-001",
  "name": "Wireless Keyboard",
  "category": "Accessories",
  "price": "29.99",
  "stock": 20,
  "reorder_level": 5
}
```

Prices are accepted as decimal values and stored as **integer cents**. Stock adjustments use transactions so a rejected operation does not change stock or history. The displayed currency is USD for this demo; there is no currency conversion or multi-currency support.

## Reports and CSV exports

Use **Products CSV** in the dashboard to download the complete product catalog, or **Movement history CSV** to download every recorded stock adjustment. The Inventory intelligence panel displays value by category and prioritizes products at or below their reorder threshold.

Reports are also accessible programmatically via `/api/reports/overview`. CSV exports include a UTF-8 BOM to help Excel detect encoding and escape spreadsheet-formula prefixes in text fields. **CSV files may still contain business-sensitive product data; do not share them publicly.**

## Security and deployment limitations

**This is a local development and portfolio demo, not a production-ready multi-user inventory service.** It has no login, roles, authentication, authorization, or CSRF protection. Do **not** expose it directly to the public internet. Start Uvicorn on `127.0.0.1` as shown above. Use HTTPS, access control, authentication, backups, and deployment hardening before hosting a real business inventory.

SQLite persists data on the local machine. Product deletion is blocked when movement history exists, preserving audit records. No real customer data is required.
